Every amiibo in the database, and whether you have it.

Identity comes from the amiibo ID inside each dump (bytes 84–91), not from the filename and not from a content hash — two dumps of the same character differ in UID and save data.
Kirby Air Riders amiibo are a character plus a vehicle, and only the character is in the amiibo ID. Every character takes every vehicle, so the full line-up is shown per character: solid means you hold that pairing, dashed means you do not. Completion still counts the character once, because that is all the database records.
